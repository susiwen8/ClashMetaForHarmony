# Clash Meta 鸿蒙版操作手册（当前版本）

本手册适用于当前 HarmonyOS 6.x 原生版本，应用名称为 **Clash Meta**。

当前版本面向 `VPN global capture` 使用路径。普通用户推荐流程是：导入并启用配置，可选执行全量测速，然后直接点击一个终端节点。应用会保存节点、申请 HarmonyOS 系统 VPN 授权并启动 VPN；VPN 已运行时，再点击其他节点会直接热切换。

> **最重要的一点：**正常情况下，选择终端节点后不需要再手动点击 **Start VPN global capture**。

## 1. 最短使用流程

首次使用时，按下面顺序操作：

1. 确认手机已经联网，并先停止手机上其他正在运行的 VPN。
2. 打开 **Clash Meta**，点击 **管理配置**。
3. 点击 **添加配置**。
4. 输入非空 **名称** 和有效 **订阅地址**，点击 **开始导入**；也可以点击 **从文件导入**。
5. 导入成功后进入 **配置详情**，点击 **启用配置**。
6. 保持在 **配置详情**，在 **代理节点** 区域点击 **管理节点**。
7. 可选：点击 **测速全部节点**，等待测速完成。
8. 点击一个可直接使用的终端节点。带有 **进入子组** 的条目只用于进入下一层，不会启动 VPN。
9. 首次启动时保持 Clash Meta 在前台，并接受 HarmonyOS 弹出的系统 VPN 授权。
10. 等待该节点显示 **当前生效**。
11. 返回首页，确认显示 **TUN capture active**，并确认 HarmonyOS 状态栏出现 VPN 图标。

完成后，设备中由该系统 VPN 会话接管的流量会使用所选节点。此时可以打开浏览器或其他应用检查网络访问情况。

判断本次 VPN 是否成功，必须同时看三处：

- 配置详情的代理节点区：所选节点显示 **当前生效**。
- Clash Meta 首页：显示 **TUN capture active**。
- HarmonyOS 状态栏：出现系统 VPN 图标。

只看到测速延迟、按钮变色或 **下次启动生效**，都不能说明这次 VPN 已经成功运行。

## 2. 使用前准备

开始前请确认：

- 手机已通过 Wi-Fi、移动网络或热点正常联网。
- 订阅或配置文件本身有效，并包含可用的代理组和终端节点。
- 手机上没有其他 VPN 正在占用系统 VPN 会话。
- 首次启动 VPN 时手机处于解锁状态，Clash Meta 位于前台。
- 优先使用 HTTPS 订阅地址。HTTP 地址没有传输加密，只应在确认来源可信时使用。

订阅地址通常包含认证信息。不要把完整订阅地址、节点内容、账号信息、设备身份或签名材料发送给他人，也不要放进截图、日志或公开文档。

## 3. 导入并启用配置

### 3.1 通过订阅地址导入

1. 首页点击 **管理配置**。
2. 在 **配置列表** 页面点击 **添加配置**。
3. 在 **导入配置** 面板填写：

   - **名称**：必填，最多 80 个字符，仅用于本机区分配置。
   - **订阅地址**：填写有效的 HTTP 或 HTTPS 地址。

4. 点击 **开始导入**。
5. 等待 **导入 → 下载 → 校验 → 保存** 完成。
6. 导入成功后，应用会自动关闭导入面板并打开 **配置详情**。
7. 点击 **启用配置**。
8. 配置启用后，详情页的 **代理节点** 区域会允许点击 **管理节点**。

如果地址使用 HTTP，应用会显示 **确认使用 HTTP**。优先改用 HTTPS；只有确认来源可信时才点击 **继续**。

> **启用配置不等于启动 VPN。**它只是把该配置设为当前配置。继续在详情页展开 **代理节点** 并点击终端节点，才会启动 VPN。

### 3.2 从文件导入

1. 进入 **管理配置 → 添加配置**。
2. 在 **导入配置** 面板点击 **从文件导入**。
3. 在系统文件选择器中选择配置文件。
4. 等待应用完成校验和保存。
5. 进入 **配置详情** 后点击 **启用配置**。

如果文件无法通过校验，请确认它是当前核心支持的 Clash/Mihomo 配置，而不是网页、压缩包、说明文本或需要其他客户端再次解密的内容。

### 3.3 刷新订阅

1. 进入 **管理配置**。
2. 点击要更新的配置，打开 **配置详情**。
3. URL 配置点击 **重新获取**。
4. 等待下载、校验和保存结束。

如果刷新失败但旧版本仍然有效，应用会保留旧版本继续使用。遇到“当前保存的订阅来源不可用”时，在详情页点击 **编辑配置**，输入新的订阅地址并点击 **保存修改**。

运行时正在切换，或系统 VPN 正在启动、恢复、停止时，配置启用、刷新、编辑和删除可能会暂时不可用。先等待首页恢复稳定，再继续操作。

### 3.4 编辑名称和订阅地址

1. 进入 **管理配置**，打开目标配置详情。
2. 点击 **编辑配置**。
3. 修改名称；远程配置还可以填写新的订阅地址。
4. 订阅地址留空表示保持当前地址，不会回显原始订阅地址或其中的认证信息。
5. 点击 **保存修改**。

只修改名称时不会访问网络。填写新订阅地址后，应用会先安全保存名称和地址，再自动下载、校验并提交新节点。VPN 正在运行时不能修改订阅地址，请先停止 VPN；名称仍可单独修改。

如果地址已经保存但自动刷新失败，页面会退出编辑并显示错误，旧节点继续保留。网络恢复后点击 **重新获取** 即可重试。

## 4. 查看并测速全部节点

### 4.1 在配置详情中展开节点

1. 确保已经启用一个有效配置。
2. 进入 **管理配置**，点击当前已启用的配置。
3. 在配置详情的 **代理节点** 区域点击 **管理节点**。
4. 展开区域顶部显示代理组；点击不同组可以切换当前列表。
5. 如果某个条目标记 **进入子组**，点击它会打开下一层代理组。继续进入，直到看到可直接选择的终端节点。

如果 **管理节点** 不可用，通常表示当前详情不是已启用配置、配置没有通过校验，或 VPN 仍处于启动、切换、恢复、停止等不稳定状态。

### 4.2 测速全部节点

1. 在目标代理组中点击 **测速全部节点**。
2. 测速开始后，按钮会变成 **取消测速**。
3. 等待进度从 **已完成 0 / n** 走到全部完成。
4. 根据结果选择节点。

测速期间，节点选择和代理组切换会暂时不可用。如需停止，点击 **取消测速**；收起代理节点区或返回配置列表时，应用也会先取消并清理未完成的测速任务。

测速结果含义：

| 显示 | 含义 |
| --- | --- |
| `n ms` | 该节点完成了本次探测；数值越低，当前探测延迟通常越小 |
| **最快** | 当前显示组中，本次测速延迟最低的可用终端节点 |
| **超时** | 在本次测试时间窗口内没有完成 |
| **不可用** | 本次连接或探测失败 |
| **已取消** | 测速任务被取消 |
| **不支持** | 该条目不是可直接测速的终端节点 |

测速只反映节点探测结果：

- 测速不会自动选择节点。
- 测速不会自动启动 VPN。
- 节点测速成功不等于系统 VPN 已接管流量。
- 延迟最低不一定代表实际下载速度最高，节点负载和网络线路仍会变化。

## 5. 一键选择节点并启动 VPN

### 5.1 推荐操作

1. 在当前配置详情展开的 **代理节点** 区域找到终端节点。
2. 点击要使用的节点一次。
3. 过程中可能显示 **切换中**、**正在启动 VPN** 或 **正在切换到 VPN**。
4. 首次使用时，接受 HarmonyOS 系统 VPN 授权。
5. 等待目标节点显示 **当前生效**。

应用会根据当前状态自动处理：

- **VPN 尚未运行**：保存所选节点并自动启动系统 VPN。
- **VPN 已运行**：在当前 VPN 会话中热切换节点，不重新创建系统 VPN 会话。
- **点击的是代理组**：只进入子组，不启动 VPN。
- **点击的就是当前生效节点**：不会重复启动或切换。

操作过程中不要连续点击多个节点。只有看到 **当前生效** 后，才表示当前 VPN 运行时已经确认使用该节点。

### 5.2 首次 VPN 授权

首次建立系统 VPN 时，HarmonyOS 会显示系统授权界面：

1. 保持手机解锁。
2. 保持 **Clash Meta** 在前台。
3. 在系统授权界面选择允许建立 VPN 连接。
4. 返回 Clash Meta，等待启动完成。

如果以前已经允许过，系统可能不会再次弹出授权；直接观察首页状态和系统 VPN 图标即可。

如果拒绝授权，首页会显示 **VPN permission was denied.**。重新点击终端节点或备用启动按钮，再在系统界面中允许授权。

### 5.3 如何确认已经成功

点击节点后，依次确认：

1. 节点显示 **当前生效**。
2. 首页 VPN 状态显示 **TUN capture active**。
3. HarmonyOS 状态栏出现系统 VPN 图标。
4. 打开浏览器或其他应用，确认目标网络可以访问。

状态栏的 VPN 图标是 HarmonyOS 系统图标，不是 Clash Meta 页面上的彩色圆点，也不是 **Continuous notification / Active** 字段。

如果前三项都正常但网站仍无法访问，优先换一个测速可用的节点。节点服务不可用、订阅规则、DNS 策略或目标网站本身也可能影响访问结果。

## 6. 运行中切换节点

VPN 已运行时切换节点：

1. 进入 **管理配置 → 当前配置详情 → 代理节点 → 管理节点**。
2. 点击另一个终端节点。
3. 等待 **正在切换到 VPN** 结束。
4. 确认新节点显示 **当前生效**。

正常热切换不会关闭再重建系统 VPN，所以状态栏 VPN 图标应保持存在。不要在 **切换中** 时连续点击其他节点。

如果出现“当前选择已临时生效，但未成功保存到下次启动”，说明本次运行已切换，但新的选择没有成功持久化。当前会话可以继续使用；若希望下次仍使用该节点，请在状态稳定后再次选择。

## 7. 首页手动启动 VPN（备用方式）

**Start VPN global capture** 是备用入口，不是推荐主流程。以下情况可以使用：

- 已经保存过节点，但 VPN 当前处于停止状态。
- 一键选择已经保存节点，却没有完成本次启动；排除故障后希望直接重试启动。

操作步骤：

1. 确认已经启用有效配置并保存过目标节点。
2. 首页点击 **Start VPN global capture**。
3. 如有系统授权，选择允许。
4. 等待首页显示 **TUN capture active**，并确认状态栏出现 VPN 图标。
5. 进入 **管理配置 → 当前配置详情**，展开 **代理节点**，确认目标节点显示 **当前生效**。

如果按钮不可点击，通常表示当前没有已启用的有效配置、没有已保存的可用节点，或运行时仍在处理中。先等待状态稳定，再回到当前配置详情的代理节点区重新选择一次。

## 8. 停止 VPN

1. 返回 Clash Meta 首页。
2. 点击 **Stop VPN global capture**。
3. 按钮显示 **处理中**、状态显示 **Stopping TUN capture** 时耐心等待，不要重复点击。
4. 等待首页恢复为 **VPN capture stopped**。
5. 确认 HarmonyOS 状态栏的 VPN 图标已经消失。

只有应用状态和系统 VPN 图标一起回落，才表示停止完成。

## 9. 常见状态说明

### 9.1 首页 VPN 状态

| 状态 | 含义 | 应该怎么做 |
| --- | --- | --- |
| **VPN capture stopped** | VPN 未运行 | 选择终端节点一键启动，或使用备用启动按钮 |
| **Waiting for VPN consent** | 等待系统 VPN 授权 | 保持 Clash Meta 在前台，处理 HarmonyOS 授权界面 |
| **Starting TUN capture** | 正在建立 TUN 和 VPN 会话 | 等待，不要重复点击 |
| **TUN capture active** | 应用运行时已进入 VPN 运行态 | 再确认节点为 **当前生效** 且状态栏有 VPN 图标 |
| **Recovering TUN capture** | Wi-Fi、移动网络或热点变化后正在恢复 | 保持网络连接并等待恢复；长时间不恢复时停止后重试 |
| **Stopping TUN capture** | 正在清理运行时并释放 VPN | 等待，不要重复点击 |
| **VPN capture error** | 启动、运行、恢复或停止失败 | 查看错误卡，按第 10 节处理 |

### 9.2 节点状态

| 状态 | 含义 | 是否表示本次 VPN 成功 |
| --- | --- | --- |
| **当前生效** | 当前 VPN 运行时已确认使用该节点 | 是，但仍需确认首页运行态和系统 VPN 图标 |
| **下次启动生效** | 节点选择已保存，但本次 VPN 启动或运行确认没有完成 | 否 |
| **正在启动 VPN** | 正在为所选节点启动 VPN | 否，继续等待 |
| **正在切换到 VPN** | 正在当前 VPN 会话中切换节点 | 否，等待 **当前生效** |
| **切换中** | 正在保存选择或处理切换 | 否，继续等待 |

> **看到“下次启动生效”时，不要把它当作连接成功。**先排除授权、其他 VPN、网络问题，然后再次点击该终端节点；也可以在节点已保存后回首页使用备用启动按钮。

## 10. 常见问题与处理方法

### 10.1 点击“开始导入”没有反应

依次检查：

1. **名称**不能为空，且不要超过 80 个字符。
2. **订阅地址**必须是完整、有效的 HTTP 或 HTTPS 地址。
3. 删除地址前后的空格后重试。
4. 确认手机本身能够联网。
5. 优先改用 HTTPS 地址。

当前版本对部分输入错误的页面提示不够明显，因此应先检查名称和地址格式。

### 10.2 浏览器能打开订阅地址，但应用仍然导入失败

浏览器能打开只说明 HTTP 请求返回了内容。Clash Meta 还需要继续完成内容解码、配置解析、核心校验和本地保存，因此浏览器可访问不等于配置一定可用。

处理顺序：

1. 在 **配置详情** 点击 **重新获取**。
2. 如果页面提示保存的来源不可用，点击 **编辑配置**，输入正确地址并点击 **保存修改**。
3. 确认返回内容是真正的 Clash/Mihomo 配置或受支持的订阅格式，而不是登录页、网页、错误页、压缩包或需要其他专用客户端解密的内容。
4. 如果服务方同时提供配置文件，可尝试 **从文件导入**。
5. 确认不再需要旧配置后，也可以删除它再重新导入。

常见错误含义：

- `SOURCE_DECRYPT_FAILED`：本机保存的订阅来源无法再解密。优先在详情页使用 **重新获取**；若提示必须修复来源，则点击 **编辑配置** 填写新地址并保存。
- `CMFA_BACKEND_ERROR`：核心在解析、校验或加载配置时失败。检查订阅返回格式和配置兼容性，然后重新获取、编辑订阅地址或改为文件导入。

不要在公开反馈中粘贴完整订阅地址或原始节点配置。

### 10.3 配置详情里的“管理节点”无法点击

1. 进入 **管理配置**。
2. 确认目标配置标记为有效。
3. 打开配置详情并点击 **启用配置**。
4. 等待 VPN 状态稳定，然后在当前配置详情的 **代理节点** 区域点击 **管理节点**。

如果配置显示 **无效** 或 **更新失败**，先在详情页重新获取，或通过 **编辑配置** 更新订阅地址。

### 10.4 点击节点后一直“正在启动 VPN”或“处理中”

1. 不要连续点击，先等待当前操作结束或出现错误卡。
2. 确认手机已解锁，Clash Meta 在前台。
3. 检查是否有 HarmonyOS VPN 授权界面等待处理。
4. 停止手机上的其他 VPN。
5. 确认当前网络能够正常上网。
6. 状态稳定后重新点击终端节点一次。
7. 如果节点已经显示 **下次启动生效**，也可以排除问题后回首页点击 **Start VPN global capture**。

系统 VPN 设置页是否列出内容不是主要判断依据。应以本次系统授权结果、Clash Meta 首页运行状态和状态栏 VPN 图标为准。

### 10.5 没有弹出 VPN 授权

- 如果以前已经允许过，系统可能不会重复弹出；检查是否直接进入 **TUN capture active** 并出现 VPN 图标。
- 如果停留在 **Waiting for VPN consent**，确保手机解锁并把 **Clash Meta** 切到前台。
- 停止其他 VPN 后，再点击所选终端节点重试。
- 如果错误卡显示 **VPN permission was denied.**，重新发起并在系统界面中允许。

### 10.6 显示“下次启动生效”

它表示节点已经保存，但本次 VPN 没有成功进入运行态，或没有完成当前节点确认。此时还不能认为已经连接。

1. 检查系统授权是否已允许。
2. 停止其他 VPN。
3. 确认手机网络正常。
4. 再次点击该终端节点。
5. 等待 **当前生效 + TUN capture active + 系统 VPN 图标** 同时出现。

### 10.7 所有节点测速都超时或不可用

1. 确认手机直连网络能够访问普通网站。
2. 切换 Wi-Fi、移动网络或热点后重新测速。
3. 在配置详情点击 **重新获取**，排除节点列表过期。
4. 确认订阅服务和节点本身仍然有效。
5. 如果只有部分节点失败，优先选择显示正常延迟的节点。

### 10.8 VPN 已运行，但仍无法访问目标网站

1. 确认当前配置详情的代理节点区显示 **当前生效**。
2. 确认首页显示 **TUN capture active**。
3. 确认状态栏有 VPN 图标。
4. 返回当前配置详情的代理节点区执行全量测速，并切换到另一个可用节点。
5. 尝试访问另一个普通网站，区分节点故障和单个目标网站故障。
6. 刷新订阅，检查配置规则和 DNS 设置是否来自有效配置。
7. 停止 VPN，等待图标消失后，再点击节点重新启动。

### 10.9 切换 Wi-Fi、移动网络或热点后断流

网络变化时应用可能显示 **Recovering TUN capture**。先保持新网络稳定并等待恢复；如果长时间没有恢复：

1. 点击 **Stop VPN global capture**。
2. 等待 **VPN capture stopped** 且状态栏图标消失。
3. 重新进入当前配置详情并展开代理节点，点击目标节点启动。

### 10.10 停止后状态栏 VPN 图标仍然存在

1. 等待 **Stopping TUN capture** 完成，不要连续点击。
2. 确认首页已经显示 **VPN capture stopped**。
3. 如果图标仍存在，检查是否有其他 VPN 接管了系统连接。
4. 必要时到 HarmonyOS 系统 VPN 设置中断开仍存在的连接，再重新打开 Clash Meta 检查状态。

## 11. 应用退到后台或重新打开

VPN 成功运行后，应用会维持后台运行所需的持续任务和通知。重新打开 Clash Meta 时，UI 会重新读取 VPN 运行状态和当前节点，短暂显示恢复中属于正常状态同步过程。

如果重新打开后长时间无法恢复正确状态：

1. 先观察状态栏是否仍有 VPN 图标。
2. 回到首页尝试正常停止。
3. 等待系统图标消失后，再进入当前配置详情的代理节点区重新选择节点。

除非你明确要删除全部本地配置和已保存来源，否则不要通过清除应用数据排查问题。

## 13. 当前版本边界与技术说明

- 当前手册面向 HarmonyOS 6.x 真机版本，机型不限。
- 节点可用性和访问效果仍取决于订阅内容、节点服务、当前网络、配置规则、DNS 和目标服务本身。
- **测速全部节点** 是节点探测工具，不是系统 VPN 成功证明。
- 系统授权通过只代表允许应用创建 VPN；仍需等待 **当前生效**、**TUN capture active** 和系统 VPN 图标共同确认。
- 应用会对公开错误信息做脱敏，但用户仍不应主动分享订阅地址、节点凭证或原始配置。

**技术说明（普通使用无需操作）：**

当前实现中，UI 与 VPN Extension 运行在 `separate PIDs`，并通过应用私有的 `LocalSocket RPC` 同步运行状态和节点操作。用户不需要配置这部分；它的作用是让首页备用启动按钮、停止按钮、节点热切换和测速操作能够到达真实的 HarmonyOS `system VPN` 运行进程。

系统 VPN 路径负责处理当前 VPN 会话接管的 `TCP / UDP / DNS` 流量。`重新打开应用后`，Clash Meta 会重新同步运行状态和当前节点；同步完成前的短暂恢复提示不代表 VPN 已经断开。
